# 🎮 Tris

Un semplice gioco del **Tris (Tic-Tac-Toe)** sviluppato in Python.

Il progetto nasce come esercizio di programmazione e implementa la logica di base del classico gioco da tavolo per due giocatori.

## ✨ Funzionalità

* 👥 Modalità per 2 giocatori
* ❌ Giocatore 1: `X`
* ⭕ Giocatore 2: `O`
* 🎯 Controllo delle mosse effettuate
* 🏆 Rilevamento automatico del vincitore
* 🤝 Rilevamento della situazione di pareggio
* 🔄 Possibilità di giocare una nuova partita

## 🛠️ Tecnologie utilizzate

* **Python 3**
* Librerie standard di Python

## 🎮 Come si gioca

Il gioco si svolge su una griglia 3×3.

I giocatori si alternano inserendo il proprio simbolo:

* `X` per il primo giocatore
* `O` per il secondo giocatore

L'obiettivo è riuscire a posizionare **tre simboli uguali consecutivi** in:

* una riga
* una colonna
* una diagonale

Il primo giocatore che raggiunge questo obiettivo vince la partita.

Se tutte le caselle vengono occupate senza che nessun giocatore riesca a completare una combinazione vincente, la partita termina in **pareggio**.
